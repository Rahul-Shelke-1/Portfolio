# Design System & Style Guide

## Color Palette
* **Primary Brand:** `#3b82f6` (Blue)
* **Secondary:** `#10b981` (Green)
* **Dark Background:** `#0f172a`
* **Light Text:** `#f8fafc`

## Image Dimensions & Rules
* **Profile Picture / Avatar:** 150px x 150px (Aspect Ratio 1:1, Max Size: 200KB)
* **Project Thumbnails:** 1200px x 630px (Aspect Ratio 16:9, Format: WebP or PNG)
* **Hero Banner:** 1920px x 1080px
